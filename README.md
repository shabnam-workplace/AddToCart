
🛒 React Add to Cart Website
This is a simple and responsive React-based e-commerce website featuring a product listing with "Add to Cart" functionality. Built using React, styled with Bootstrap, and enhanced with FontAwesome icons. Navigation is handled using React Router DOM.

🚀 Features
🧾 Product listing page

🛒 Add to Cart functionality

📦 Cart management with quantity update and removal

🔗 Navigation using React Router

📱 Fully responsive design with Bootstrap

⭐ FontAwesome icons for better UX

🛠️ Technologies Used
React – Frontend library

Bootstrap – Styling framework

FontAwesome – Icons

React Router DOM – Routing between pages
🌐 Routes

Route	Description
/	Home page
/products	Product listing
/cart	View and manage your cart
📦 Example Products (Optional)
You can use local data or fetch products from an API like FakeStoreAPI.
